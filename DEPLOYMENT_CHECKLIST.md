# Deployment Checklist\n\nComplete this checklist before deploying your gaming website to production.\n\n## Pre-Deployment\n\n### Code Quality\n- [ ] All tests pass locally: `pytest tests/ -v`\n- [ ] Code follows style guide\n- [ ] No hardcoded secrets or API keys\n- [ ] README is up to date\n- [ ] Dependencies are pinned in requirements.txt\n- [ ] No debug mode enabled\n\n### Environment Setup\n- [ ] `.env.production.example` file exists\n- [ ] All required environment variables documented\n- [ ] OpenWeatherMap API key obtained (if using weather features)\n- [ ] Database credentials prepared\n- [ ] Secret keys generated (use: `openssl rand -hex 32`)\n\n### Security\n- [ ] CORS origins configured correctly\n- [ ] Secret keys are strong and unique\n- [ ] Database password is strong\n- [ ] JWT secrets set\n- [ ] HTTPS/SSL will be enabled\n- [ ] Security headers configured (in nginx.conf)\n\n## Deployment Options\n\n### Option 1: Render (Recommended)\n\n**Prerequisites:**\n- [ ] GitHub account with repository access\n- [ ] Render account (https://render.com)\n\n**Setup Steps:**\n- [ ] Read [RENDER_QUICKSTART.md](RENDER_QUICKSTART.md)\n- [ ] Connect GitHub to Render\n- [ ] Create new Web Service\n- [ ] Add PostgreSQL database\n- [ ] Configure environment variables\n- [ ] Set deploy hook URL\n- [ ] Enable auto-deploy from main branch\n- [ ] Add custom domain (optional)\n- [ ] Configure SSL certificate (auto)\n\n**Post-Deployment:**\n- [ ] Test application health: `curl https://your-app.onrender.com/health`\n- [ ] Check logs for errors\n- [ ] Verify database connection\n- [ ] Test all features (clock, weather, etc.)\n- [ ] Verify API endpoints work\n- [ ] Test weather API integration\n\n### Option 2: Railway\n\n**Prerequisites:**\n- [ ] Railway account (https://railway.app)\n- [ ] GitHub connected\n\n**Setup Steps:**\n- [ ] Create new Railway project\n- [ ] Connect GitHub repository\n- [ ] Add PostgreSQL plugin\n- [ ] Configure environment variables\n- [ ] Set deployment settings\n- [ ] Enable automatic deployments\n\n**Post-Deployment:**\n- [ ] Verify app is running\n- [ ] Check logs\n- [ ] Test endpoints\n\n### Option 3: Heroku\n\n**Prerequisites:**\n- [ ] Heroku account\n- [ ] Heroku CLI installed\n- [ ] Git repository initialized\n\n**Setup Steps:**\n- [ ] Run: `heroku create gaming-website-unique`\n- [ ] Add PostgreSQL: `heroku addons:create heroku-postgresql:hobby-dev`\n- [ ] Set config vars: `heroku config:set KEY=value`\n- [ ] Deploy: `git push heroku main`\n- [ ] Configure custom domain\n- [ ] Enable automatic SSL\n\n**Post-Deployment:**\n- [ ] Check logs: `heroku logs --tail`\n- [ ] Verify health: `curl https://your-app.herokuapp.com/health`\n- [ ] Test features\n\n### Option 4: AWS EC2\n\n**Prerequisites:**\n- [ ] AWS account with EC2 access\n- [ ] SSH key pair created\n- [ ] Security group configured\n\n**Setup Steps:**\n- [ ] Launch t2.micro instance\n- [ ] Install dependencies\n- [ ] Clone repository\n- [ ] Configure environment\n- [ ] Setup Nginx reverse proxy\n- [ ] Install Gunicorn\n- [ ] Configure systemd service\n- [ ] Setup SSL with Let's Encrypt\n- [ ] Configure custom domain\n\n**Post-Deployment:**\n- [ ] SSH into instance\n- [ ] Check service status: `systemctl status gaming-website`\n- [ ] View logs: `journalctl -u gaming-website -f`\n- [ ] Test endpoints\n- [ ] Verify SSL certificate\n\n## Post-Deployment Configuration\n\n### Domain Setup\n- [ ] Purchase domain from registrar\n- [ ] Update DNS records (CNAME or A record)\n- [ ] Wait for DNS propagation\n- [ ] Verify domain is working\n- [ ] SSL certificate is valid\n\n### Monitoring & Logging\n- [ ] Set up error tracking (optional: Sentry)\n- [ ] Configure log aggregation\n- [ ] Set up alerts for errors\n- [ ] Monitor response times\n- [ ] Track database performance\n\n### Database\n- [ ] Create initial database\n- [ ] Run migrations (if applicable)\n- [ ] Backup initial state\n- [ ] Test backup/restore process\n- [ ] Set up automated backups\n\n### Email Configuration (If Needed)\n- [ ] Configure SMTP server\n- [ ] Set up email templates\n- [ ] Test email sending\n- [ ] Configure transactional emails\n\n## Testing in Production\n\n### Functionality Tests\n- [ ] Home page loads\n- [ ] User authentication works\n- [ ] Games are playable\n- [ ] Leaderboards display correctly\n- [ ] Digital clock feature works\n- [ ] Weather dashboard loads and updates\n- [ ] Weather API integration works\n- [ ] City search autocomplete works\n- [ ] Multiple city tracking works\n\n### Performance Tests\n- [ ] Page loads in < 3 seconds\n- [ ] API responses < 500ms\n- [ ] Database queries optimized\n- [ ] Static files cached properly\n- [ ] Images optimized\n\n### Security Tests\n- [ ] HTTPS is enforced\n- [ ] Security headers present\n- [ ] CORS correctly configured\n- [ ] SQL injection prevention working\n- [ ] XSS protection enabled\n- [ ] CSRF tokens working\n- [ ] Rate limiting active\n\n### API Tests\n\n**Clock API:**\n```bash\ncurl https://your-domain.com/api/clock/time?tz=UTC\ncurl https://your-domain.com/api/clock/timezones\n```\n\n**Weather API:**\n```bash\ncurl https://your-domain.com/api/weather/current?city=London\ncurl https://your-domain.com/api/weather/forecast?city=London\ncurl https://your-domain.com/api/weather/search?q=Paris\n```\n\n**Health Check:**\n```bash\ncurl https://your-domain.com/health\n```\n\n## GitHub Actions Setup\n\n- [ ] Repository created on GitHub\n- [ ] Read `scripts/setup-github-actions.sh`\n- [ ] Create `.github/workflows/deploy.yml` file\n- [ ] Get deploy hook URL from Render/Railway/Heroku\n- [ ] Add DEPLOY_HOOK secret to GitHub\n- [ ] Test CI/CD pipeline:\n  - [ ] Push to main branch\n  - [ ] Verify tests run\n  - [ ] Verify deployment triggers\n  - [ ] Check application deployed successfully\n\n## Ongoing Maintenance\n\n### Weekly\n- [ ] Check application logs for errors\n- [ ] Monitor resource usage\n- [ ] Verify backups completed\n- [ ] Check security alerts\n\n### Monthly\n- [ ] Update dependencies\n- [ ] Review and rotate secrets\n- [ ] Test disaster recovery\n- [ ] Analyze performance metrics\n- [ ] Review security audit logs\n\n### Quarterly\n- [ ] Major version updates\n- [ ] Database optimization\n- [ ] Security assessment\n- [ ] Capacity planning\n\n## Rollback Plan\n\n### If Deployment Fails\n\n**On Render:**\n1. Go to Dashboard → Deployments\n2. Click on previous successful deployment\n3. Click \"Redeploy\"\n\n**On Heroku:**\n```bash\nheroku releases\nheroku rollback v123  # Replace with desired version\n```\n\n**On AWS:**\n```bash\ngit log --oneline  # Find previous commit\ngit revert <commit-hash>\ngit push\n```\n\n### Communication\n- [ ] Notify team/users of issue\n- [ ] Document what went wrong\n- [ ] Implement fix\n- [ ] Test thoroughly\n- [ ] Redeploy\n- [ ] Verify working\n- [ ] Post-incident review\n\n## Documentation\n\n- [ ] Update deployment guide if needed\n- [ ] Document any custom configurations\n- [ ] Create runbook for common issues\n- [ ] Document API changes\n- [ ] Keep team informed of changes\n\n## Sign-Off\n\n- [ ] Code review completed\n- [ ] QA testing passed\n- [ ] Performance verified\n- [ ] Security checks passed\n- [ ] Deployment checklist completed\n- [ ] Team lead approval obtained\n- [ ] Ready for production deployment\n\n---\n\n**Deployment Date:** ____________  \n**Deployed By:** ____________  \n**Version:** ____________  \n**Notes:** ____________\n\n---\n\n## Support & Resources\n\n- **Render Docs:** https://render.com/docs\n- **Railway Docs:** https://docs.railway.app\n- **Heroku Docs:** https://devcenter.heroku.com\n- **AWS Docs:** https://docs.aws.amazon.com\n- **OpenWeatherMap API:** https://openweathermap.org/api\n\nFor additional help, see [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)\n"
